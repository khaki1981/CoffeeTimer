# Coffee Bean Memo 設計書

## 目的

Coffee Timer を単なるタイマーではなく、

**「コーヒーライフを記録するアプリ」**

へ進化させる。

タイマーだけではなく、

* コーヒー豆
* 抽出レシピ
* 味の評価
* 購入履歴

をまとめて管理できるようにする。

# 最終目標

**「タイマー」**

ではなく

**「コーヒーを淹れて、記録し、振り返り、次回さらに美味しく淹れるためのアプリ」**

へ進化させる。
