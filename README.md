# Coffee Timer

複数の抽出工程をメニューとして保存し、順番に実行できるコーヒー抽出タイマーです。

## 主な機能

- 抽出メニューの作成・編集
- 蒸らしから各投目への自動進行
- 選択可能な工程終了通知音
- タイマー操作と連動するBGM
- 一時停止・リセット
- メニュー、選択状態、音設定のブラウザ保存
- スマートフォン対応

## 起動方法

`index.html`をブラウザで開いてください。外部ライブラリやビルド作業は不要です。

## ファイル構成

```text
.
├── index.html
├── style.css
├── main.js
├── assets/
│   └── music/
│       └── morningcoffee.mp3
└── README.md
```

アプリ本体はプロジェクト直下の`index.html`です。`CoffeeTimer/`などの別フォルダには複製しません。
